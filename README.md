Vehicle Booking System

A web-based vehicle booking system that allows users to browse available vehicles and make bookings through an easy-to-use interface.

📌 Features
User registration and login
Browse available vehicles
Vehicle booking
View booking details
Manage bookings
Database integration
User-friendly interface
🛠️ Technologies Used
HTML
CSS
JavaScript
PHP
MySQL
XAMPP
💻 How to Run the Project
1. Install XAMPP

Install XAMPP and start:

Apache
MySQL
2. Clone the repository
git clone https://github.com/KunalPaithane/vehicle-booking-system.git
3. Move the project

Place the project inside:

C:\xampp\htdocs\
4. Set up the database
Open phpMyAdmin.
Create a database for the project.
Import the project's .sql database file.
Update the database connection settings in the PHP configuration file if required.
5. Run the project

Open your browser and go to:

http://localhost/vehicle-booking-system/
